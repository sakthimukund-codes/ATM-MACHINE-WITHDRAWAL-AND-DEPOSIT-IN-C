ATM Withdrawal and Deposit System in C

Description

A simple ATM simulation program written in C. It allows users to choose between withdrawing and depositing money using a menu.

Features

- Initial balance of ₹5000
- Withdraw money
- Deposit money
- Display updated balance
- Validate the entered amount

Technologies Used

- C Programming
- "stdio.h"

How to Run

1. Copy the code into a file named "atm.c".
2. Compile the program using a C compiler.
3. Run the program.
4. Enter your choice:
   - "1" for Withdrawal
   - "2" for Deposit
5. Enter the amount.

Sample Output

1. Withdrawal
2. Deposit
1
Enter amount: 1000
Balance = 4000

Concepts Used

- Variables and data types
- "printf()" and "scanf()"
- "if-else" statements
- Logical operators ("&&")
- Arithmetic operators

Note

This is a beginner-level practice project. It does not connect to a real bank account.
